Explicación de la práctica

En esta práctica se trabajo con hilos en JavaFX para simular el procesamiento de clientes y productos 
al mismo tiempo, se utilizaron Thread y runnable para ejecutar ambos procesos por separado, y 
Platform.runLater() para actualizar las barras de progreso sin bloquear la ventana
también se agregaron botones para iniciar, detener y reiniciar cada proceso de forma independiente.
